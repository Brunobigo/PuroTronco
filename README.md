# Puro Tronco - Landing Page 🪵

Este repositório contém o código-fonte da página temporária de "Em Construção" da **Puro Tronco - Arte em Madeira**. 
O site foi construído em HTML5 e CSS3 e está configurado para ser hospedado gratuitamente através do **GitHub Pages**.

## 🚀 Como visualizar localmente
Não é necessária nenhuma instalação complexa. Para ver o site no seu computador:
1. Faça o clone ou baixe este repositório.
2. Certifique-se de que a imagem `PuroTronco.jpg` está na mesma pasta do arquivo `index.html`.
3. Dê um duplo clique no arquivo `index.html` para abri-lo no seu navegador (Chrome, Edge, Firefox, etc.).

## 📁 Estrutura de Arquivos
- `index.html`: Arquivo principal contendo a estrutura e o estilo (CSS) da página.
- `PuroTronco.jpg`: Logotipo utilizado na página (deve ser inserido manualmente na pasta).
- `.gitignore`: Arquivo de configuração do Git para ignorar arquivos desnecessários.
- `README.md`: Este arquivo de documentação.
